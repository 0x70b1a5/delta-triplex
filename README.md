# Delta Triplex Site

The Site embeds the standalone game at public/game.html without changing its shared C/raylib engine. The editable source and tests are in game-source/. See its README for the Emscripten build. After rebuilding, copy game-source/web/index.html to public/game.html and rebuild this Site.

Use the supervised Sites preview and standard Sites build/publish workflow. Browser-local saves are scoped to this Site origin.
